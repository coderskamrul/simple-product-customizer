## Have you checked for common technical issues?

Please ensure that your plugin adheres to best practices, including the following:

### ![🔴](https://fonts.gstatic.com/s/e/notoemoji/17.0/1f534/32.png) Use wp_enqueue commands

 **![ℹ️](https://fonts.gstatic.com/s/e/notoemoji/17.0/2139_fe0f/32.png) Why it matters** : Because of performance and compatibility, please make use of the built in functions for including static and dynamic JS and/or CSS.

 **![🔍](https://fonts.gstatic.com/s/e/notoemoji/17.0/1f50d/32.png) Identify JS and CSS outputs** : Look for any `<script>` or `<style>` HTML tags in your plugin. In the majority of cases you could enqueue them.

 **![🛠](https://fonts.gstatic.com/s/e/notoemoji/17.0/1f6e0/32.png) Fix it** : Make use of the specific function for enqueue them:

| Type of code | Functions                                                                      |
| ------------ | ------------------------------------------------------------------------------ |
| Static JS    | `wp_register_script()`, `wp_enqueue_script()`, `admin_enqueue_scripts()` |
| Inline JS    | `wp_add_inline_script()`                                                     |
| Static CSS   | `wp_register_style()`, `wp_enqueue_style()`                                |
| Inline CSS   | `wp_add_inline_style()`                                                      |

![👉](https://fonts.gstatic.com/s/e/notoemoji/17.0/1f449/32.png)

 In the public pages you can enqueue them using the hook `wp_enqueue_scripts()`.
![👉](https://fonts.gstatic.com/s/e/notoemoji/17.0/1f449/32.png)

 In the admin pages you can enqueue them using the hook `admin_enqueue_scripts()`. You can also use `admin_print_scripts()` and `admin_print_styles()`.
![👉](https://fonts.gstatic.com/s/e/notoemoji/17.0/1f449/32.png)

 As of WordPress 6.3, you can [easily pass attributes like defer or async](https://make.wordpress.org/core/2023/07/14/registering-scripts-with-async-and-defer-attributes-in-wordpress-6-3/), as of WordPress 5.7, you can [pass other attributes by using functions and filters](https://make.wordpress.org/core/2021/02/23/introducing-script-attributes-related-functions-in-wordpress-5-7/).

Example:

```
function prodprop_enqueue_script() {
    wp_enqueue_script( 'prodprop_js', plugins_url( 'inc/main.js', __FILE__ ), array(), PRODPROP_VERSION, true );
}
add_action( 'wp_enqueue_scripts', 'prodprop_enqueue_script' );
```

Your JS/CSS is now  **enqueued** !
